# Fabrantic prototype: multi-page site

A static, multi-page prototype of fabrantic.com. It keeps the earlier UI improvements and adds the SEO structure: one URL per page, canonical tags, Open Graph and Twitter tags, JSON-LD, a sitemap and a robots file.

**All copy is original.** Only the brand name, the product names (VoiceRouter, AI Co-Founder) and the tagline "Build more. Own more." are kept from the live site.

## What's here

| Path | What it is |
|---|---|
| `site/` | The site. Serve this folder as the web root. |
| `site.zip` | The same folder, zipped |

| `QA_REPORT.md` | Before and after test results, with numbers |
| `README.md` | This file |

```
site/sitemap.xml, site/robots.txt
site/assets/site.js                              shared script (menu, demo, form)
site/assets/og/*.png                             share images (PLACEHOLDERS)
```

The review-only share-previews page has been removed from the build.

To run it locally:

```bash
python3 -m http.server 8000 --directory site
```

Then open http://localhost:8000/. Links are root-relative (`/voicerouter/`), so the folder has to be served as the site root, not opened as a file.

## What's still unverified or placeholder

- **Share images are placeholders.** The seven files in `site/assets/og/` are generated 1200×630 PNGs labelled "PLACEHOLDER". Replace them with designed images before publishing; the file names are referenced by each page's `og:image` and `twitter:image`.
- **Lighthouse scores.** Not run, so accessibility and performance scores are unverified before and after. Page weight dropped from 337,874 bytes to 51,911–60,270 bytes per page (see `QA_REPORT.md`), but whether that reaches the earlier 99–100 performance score is unknown until Lighthouse runs.
- **The live-site comparison.** The figures for fabrantic.com in the earlier review (touch targets, blank screens) were measured once in this session and not repeated. They need network access to fabrantic.com to re-check.
- **Google Eloquent's platform.** The site says news reports in May 2026 put it on iPhone, marked "confirm before publishing". Android availability is deliberately not stated.
- **Region-dependent figures.** Wispr Flow's Pro (₹320) and Growth (₹480) prices were seen from India and vary by region. The site says so. Check the price shown in your target market before publishing.
- **Other competitor facts.** These come from wisprflow.ai/pricing and the superwhisper.com homepage, as checked on 11 Oct 2026 (supplied in the brief, not re-fetched here). Re-check before publishing. SuperWhisper's language count is shown as "Not checked".
- **Reduced motion and font loading.** Both are in the code but weren't emulated or measured in this environment.
- **Rich results.** The JSON-LD parses, but Google's Rich Results Test wasn't run. `SoftwareApplication` has no `offers` or `aggregateRating` because pricing isn't announced, so it may not qualify for rich results.
- **Forms are not connected.** The early-access form validates and shows feedback but sends nothing, and says so on every page.
- **Demo content is illustrative.** The VoiceRouter demo uses an invented note, workspace and score, labelled "Illustrative only".
- **Press page gaps.** It still needs a press contact, founder name and photo, logo files and launch dates.

## Rebuilding

The site is generated by `build_site.py`, which reads the merged prototype's CSS and the AI Co-Founder diagram, then applies the fixes. The scripts are in this session's scratch folder and aren't part of the deliverable. Ask if you want them included.
